# 🛒 HomeMart — Smart Grocery Shopping

**Your groceries, your way.** 🏡

HomeMart is a grocery shopping web application designed to make everyday grocery shopping more convenient and accessible. It provides a digital platform for users to explore a grocery shopping experience from the comfort of their homes.

🌐 **Live Website:** https://homemart.onrender.com/

---

## ✨ About the Project

HomeMart was developed as a collaborative project with the goal of making grocery shopping simpler through a user-friendly web interface.

The project focuses on creating a convenient online grocery shopping experience with an emphasis on usability, accessibility, and a clean interface.

## 🎯 Project Objectives

- 🛍️ Provide a digital grocery shopping experience.
- 🏠 Make everyday grocery shopping more convenient.
- 💻 Create a user-friendly and accessible interface.
- 🎨 Apply web development and UI/UX design principles to a practical project.
- 🤝 Collaborate as a team to design and develop a web application.
